My initial idea for this project is that I want to be able to create a toolbox which will be an MCP server that Claude is able to connect to and give it capabilities to produce artwork. I want to make this modular so that we can have different types of tools, such as one might be a suite of painting tools that is able to allow Claude to create a painting, and then the other tool might be something similar to a 3D generator of objects. And so these two things will be separate and configurable based off of how we actually want to set up the build parameters and which tools we include. The other thing which will be necessary is a way to actually view and keep track of the state, and for each different tool there are going to be different states that we need to keep track of. So, for example, the painting tool will need to have something which is a canvas, but the 3D builder might need something which is a three-dimensional matrix, and then to view it we will also need a viewing tool.

As of right now, the way that I'm envisioning the user to be able to start the state machine and viewer will be that they need to start it via command line. This is not extremely user friendly, but can be improved upon in the future.

So for now I will focus on just getting the painting tool layed out. I will stick with the dotnet C# framework as much as possible because of my familarity with it, and only use something outside of that enviornment if there is a justification for doing so. 

For the painting tool, I am wanting to be able to have a canvas which is viewable from the browser. And I'm thinking that we will be able to place brush strokes onto the canvas. So this would look something like place brush stroke, start position, stop position, and color. And then I would have some kind of image of a brush stroke or some repersentation of an actual paint stroke, that is able to be placed. I will also need to consider token cost, so maybe the agent will be able to input multiple brush strokes at once.
